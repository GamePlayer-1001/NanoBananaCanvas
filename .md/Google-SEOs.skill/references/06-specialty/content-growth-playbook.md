# SEO 内容增长与运营手册

用于需要制定关键词体系、内容节奏、站外拓展、月度复盘和增长闭环的任务。本文档来自 `seo优化.txt` 中与增长运营相关的可执行部分。

## 使用场景

- 需要从 0 到 1 建立关键词和内容体系
- 需要给网站制定月度内容计划
- 需要做内容站、工具站、博客站的 SEO 增长策略
- 需要搭建“生产 - 发布 - 复盘”的运营闭环

## 关键词系统

按搜索意图拆分：

| 类型 | 特征 | 优先级 |
| --- | --- | --- |
| 高意图词 | 接近转化、工具名、产品名、解决方案词 | 最高 |
| 长尾词 | 问题型、场景型、教程型 | 高 |
| 品类词 | 泛主题、竞争大 | 中 |
| 灵感词 | 趋势、合集、案例 | 中 |

推荐流程：

1. 从 Search Console 拉已有曝光词
2. 用 Google Trends、自动补全、People Also Ask 扩展
3. 按意图、难度、转化相关性分组
4. 分配到页面类型：首页、功能页、聚合页、教程页、案例页

## 页面类型设计

常见组合：

- 核心产品页：吃高意图词
- 标签 / 分类聚合页：吃品类词与场景词
- 教程文章：吃问题型长尾词
- 合集文章：吃灵感词和比较词
- FAQ / 帮助页：吃低竞争问答词

避免：

- 一个关键词让多个模板互相打架
- 内容页没有内链回到聚合页
- 所有文章都在讲同一件事，只换标题

## 内容模板

教程型文章模板：

1. 开场说明问题与结果
2. `What You'll Learn`
3. 分步骤主体
4. 常见问题
5. 相关资源 / 产品页 / 相关文章

合集型文章模板：

1. 开场定义使用场景
2. 快速导航
3. 分类分组内容
4. 使用说明
5. FAQ

## 发布节奏

基础节奏建议：

- 每周 1 篇教程
- 每周 1 篇合集或案例
- 每月 1 次旧内容刷新
- 每月 1 次关键词缺口复盘

先求稳定，不要求数量激进扩张。更新频率要和可维护能力匹配。

## 站外拓展

可以做的自然扩展：

- 工具导航站提交
- 社区问答与经验分享
- 社交媒体素材二次分发
- 行业资源页合作

执行原则：

- 先提供价值，再提及产品
- 不做明显垃圾外链
- 让外部入口能落到最相关的内页

## 免费工具清单

| 工具 | 主要用途 |
| --- | --- |
| Google Search Console | 查询、页面、点击、展示、CTR |
| GA4 | 页面行为与转化辅助观察 |
| Google Trends | 趋势判断 |
| Rich Results Test | 结构化数据验证 |
| PageSpeed Insights | 页面性能 |
| Screaming Frog | 技术抓取与批量审查 |

## 月度复盘框架

每月最少回答这些问题：

1. 哪些页面新增了曝光但 CTR 低
2. 哪些关键词排名上升或下降
3. 哪些页面收录了但没有带来点击
4. 哪些新内容被快速索引，哪些没有
5. 是否出现技术异常、模板退化、内容同质化

复盘输出建议：

- 本月发现
- 本月问题
- 下月行动
- 内容计划

## 90 天增长节奏

### 0-30 天

- 完成技术基础
- 建关键词清单
- 发布首批核心内容

### 30-60 天

- 根据 Search Console 调整标题和内链
- 扩展长尾内容
- 开始做外部分发

### 60-90 天

- 刷新高展示低点击页面
- 扩展表现最好的主题簇
- 清理表现差且重复的内容

## 输出模板

当用户要求“增长方案”时，优先输出：

### 目标

- 3 个月目标
- 6 个月目标

### 页面策略

- 哪些页面吃哪些词

### 内容节奏

- 每周 / 每月发什么

### 分发策略

- 站内怎么串联
- 站外怎么扩散

### 复盘机制

- 每月看哪些指标
- 根据什么信号调整
