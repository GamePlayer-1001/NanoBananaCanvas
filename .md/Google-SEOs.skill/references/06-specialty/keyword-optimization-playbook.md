# SEO 关键词优化手册

用于需要做关键词布局、关键词映射、页面级优化、关键词蚕食治理和标题 CTR 调整的任务。本文档关注的是“一个页面该吃哪些词、如何吃、怎么验证是否吃对了”。

## 使用场景

- 新页面上线前需要做关键词规划
- 旧页面排名不稳，需要重做关键词布局
- 多个页面争抢同一关键词，需要治理关键词蚕食
- 已有曝光但 CTR 低，需要调整标题和摘要

## 先做关键词分组

不要直接把一堆词塞进一个页面。先按意图聚类：

| 类型 | 特征 | 对应页面 |
| --- | --- | --- |
| 主关键词 | 页面最核心的目标词 | 1 个主页面 |
| 次关键词 | 与主词同意图的变体 | 同页承接 |
| 支撑词 | 子问题、属性、场景词 | 页面正文与 FAQ |
| 否定词 | 不该由本页承接的词 | 分流到其他页 |

判断是否应该归到同一页，先看：

- 搜索意图是否相同
- 结果页是否高度重合
- 用户完成任务的路径是否一致

## 页面与关键词映射

目标是做到“一页一主意图”，而不是“一页所有词”。

推荐映射：

- 首页：品牌词、核心品类词
- 产品 / 服务页：高商业意图词
- 分类 / 聚合页：品类词、场景词
- 博客 / 教程页：问题型、长尾型、对比型词
- FAQ / 帮助页：细碎问答词

危险信号：

- 两个页面 Title 都在抢同一个主词
- 聚合页和详情页都想吃完全相同的 query
- 文章页去抢应该由产品页承接的转化词

## 页面级关键词布局

至少检查这些位置：

| 位置 | 原则 |
| --- | --- |
| Title | 主词靠前，但保持可读性 |
| H1 | 与主意图一致，不必机械复读 Title |
| URL | 简洁且反映主题 |
| 首段 | 明确主题与用户收益 |
| 小标题 | 覆盖支撑词和子问题 |
| 锚文本 | 站内链接使用自然描述 |
| 图片 alt | 只在相关时自然补充语义 |

不要做的事：

- 关键词堆砌
- 为了插词牺牲可读性
- 所有 heading 都重复同一关键词
- 用 schema 字段作弊塞词

## 关键词蚕食治理

出现这些现象时要警惕：

- 同一个 query 在 Search Console 中被多个 URL 轮流曝光
- 排名忽上忽下，落地页经常变化
- 两个页面主题相近，只是标题写法不同

治理方法：

1. 选定主承接页
2. 弱页改做支撑页、FAQ 页或跳转页
3. 调整 canonical、内链和锚文本
4. 重写弱页的关键词目标，避免继续互抢

必要时：

- 合并内容
- 做 301
- 把聚合页与详情页职责重新划清

## CTR 优化

当排名有了、点击不足时，优先检查：

- Title 是否太泛
- Description 是否没说明价值
- 是否缺少年份、数量、场景、对比信息
- 页面是否有资格拿富结果

可尝试的方向：

- 明确结果类型：指南、模板、案例、清单、工具
- 强化差异点：免费、完整、快速、适合谁
- 标题中加入更具体的用户意图词，而不是一味加大词量

## 刷新与迭代

关键词优化不是一次性动作。建议周期：

- 新页面上线后 2 到 4 周看首次曝光
- 每月看查询词变化和页面匹配度
- 每季度重看主题簇是否需要扩页、并页或重写

优先处理：

- 高展示低点击页
- 已排到 5 到 20 名的潜力页
- 多 URL 抢同词的页面组

## 关键词优化输出模板

### 页面定位

- 当前页面应该承接什么主意图

### 关键词映射

- 主关键词
- 次关键词
- 支撑词
- 不应承接的词

### 页面修改建议

- Title / H1 / URL / 首段 / 小标题 / FAQ / 内链

### 风险

- 是否存在蚕食
- 是否有堆砌风险
- 是否和站内其他页职责冲突

### 验证

- 观察哪些 query
- 看哪个 URL 曝光
- 复查 CTR、平均排名、查询覆盖范围
