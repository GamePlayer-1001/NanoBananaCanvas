# 06-specialty - 专项实施手册

本目录承载两类内容：

1. Google 官方文档难以直接给出、但在 SEO 项目落地时反复需要的工程化实施方法。
2. 从 `seo优化.txt` 整理出的可复用实战手册，用于把规则转成方案、清单和执行顺序。

## 当前文件

- `implementation-playbook.md`
  技术 SEO 总手册，覆盖 `robots.txt`、`sitemap.xml`、canonical、重定向、页面级 SEO、性能、验证与上线清单。
- `multilingual-seo-playbook.md`
  多语言 SEO 手册，覆盖 URL 结构、`hreflang`、本地化深度、地域跳转和验证方式。
- `geo-seo-playbook.md`
  Geo SEO 手册，覆盖国家 / 区域 / 城市级目标市场、地域页设计、本地信号与 doorway 风险规避。
- `keyword-optimization-playbook.md`
  关键词优化手册，覆盖关键词聚类、页面映射、页面级布局、关键词蚕食与 CTR 优化。
- `content-growth-playbook.md`
  增长与运营手册，覆盖关键词系统、页面策略、内容节奏、站外拓展和月度复盘。

## 使用原则

- 先读 `SKILL.md` 判断问题类型，再进入最相关的一份手册。
- 这些手册补充的是“如何落地”，不是替代 Google 官方政策。
- 当专项手册和官方文档表述层级不同，以官方规则为准，专项手册负责补全实施路径。

## 适用任务

- “给我完整 SEO 实施方案”
- “多语言站点怎么做 SEO”
- “帮我做 geo SEO / 城市页 / 区域页方案”
- “这些页面怎么做关键词优化”
- “给我一个 90 天 SEO 增长计划”
- “上线前需要检查哪些 SEO 项”
