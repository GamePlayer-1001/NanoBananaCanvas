# Nano Banana Canvas - 私域转化与留存话术

> 用途：给企微、微信群、Discord、Telegram、私信、邮件、用户访谈和社群运营统一承接话术。

## 私域核心目标

1. 让用户先进入工作台，而不是先理解所有概念
2. 让用户第一次跑通一条流程，而不是只看功能介绍
3. 让用户看到模板、社区、Agent、克隆的复用价值
4. 让用户从“偶尔试一下”变成“把项目放进来”

## 用户分层

### 1. 围观型用户

特征：
- 看过内容，没注册
- 觉得有意思，但没有明确任务

承接重点：
- 先让他理解产品不是单点生成工具
- 给最轻的体验路径

推荐话术：
- 如果你之前用过 AI 出图工具，这个产品最大的不同，是它能把整条创作流程放到一张画布里。
- 你不用先研究复杂参数，先从模板或社区克隆开始，跑通一次就能理解它的价值。

### 2. 试玩型用户

特征：
- 已注册
- 还没跑通第一条工作流

承接重点：
- 让他完成第一次成功产出
- 用模板和 Agent 降低空白焦虑

推荐话术：
- 你现在最适合的不是从零搭，而是先选一个模板或克隆一个现成流程，再让 Agent 帮你改成自己的方向。
- 先做出第一版结果，比一开始就追求最复杂流程更重要。

### 3. 生产型用户

特征：
- 已经开始跑图、跑视频、跑文本流程
- 在意效率、稳定性、成本

承接重点：
- 强化复用和沉淀
- 引导到自带 Key、账单页、模板库

推荐话术：
- 你现在已经不只是“用 AI”，而是在搭自己的生产链了。下一步更值钱的是把好流程保存下来，变成团队可复用模板。
- 如果你已经有固定模型偏好，可以切到自带 Key 模式，灵活度和成本可控性会更高。

### 4. 付费犹豫型用户

特征：
- 已体验
- 但还没决定升级或充值

承接重点：
- 让他看到“持续生产”价值
- 不要只讲功能，要讲节奏和产能

推荐话术：
- 免费路径适合先验证流程，但一旦你开始稳定生产，瓶颈往往就不在会不会用，而在额度、吞吐和节奏。
- 升级的意义不是多一个高级按钮，而是让你把创作变成稳定交付。

## 私域转化话术模板

### 1. 首次欢迎话术

欢迎你进来。这个产品不是让你再学一个 AI 按钮，而是帮你把文本、图片、视频这些能力串成一条可复用流程。  
如果你是第一次用，最推荐的路径是：先开一个模板，再让 Agent 帮你改成你想要的方向。

### 2. 沉默用户唤醒话术

你上次已经进过工作台了，如果当时觉得有点空，不是你不会用，而是这类工具最怕从空白开始。  
我建议你这次直接从模板或社区克隆开始，先跑通一次，再去理解每个节点会轻松很多。

### 3. 解释产品差异的话术

市面上很多 AI 工具强在单点生成，但弱在流程复用。  
我们更想解决的是：你做出一条能稳定交付的工作流，下次能继续改，团队也能继续用。

### 4. 解释 Agent 价值的话术

这里的 Agent 不是一个单独聊天框，它更像画布里的助手。  
它可以帮你解释当前流程、诊断哪里卡住、给出优化提案，甚至基于模板帮你改方向。

### 5. 解释双模式的话术

如果你只是想快速体验，可以直接跑平台模式。  
如果你已经有自己的模型、Key 或预算策略，也可以切到自带 Key 模式，控制权会更强。

### 6. 解释升级价值的话术

升级不是为了“解锁一个功能”，而是为了让你的工作流能更持续、更稳定地生产。  
当你开始把这个工具用于连续创作、接单、团队协作时，额度和吞吐就会直接影响效率。

## 私域留存动作设计

### 1. 第一次留存

- 引导用户 24 小时内跑通第一条模板
- 给一个“从模板到个人版本”的最短路径

推荐触达：
- 你不需要从空白开始，直接发你一个适合上手的模板，先跑一版结果最重要。

### 2. 第三天留存

- 让用户从“试一次”进入“再改一次”
- 强调 Agent 优化和模板改造

推荐触达：
- 如果你已经跑出第一版了，下一步最有价值的是让 Agent 帮你继续优化，而不是重新从零做一遍。

### 3. 第七天留存

- 引导用户保存自己的工作流
- 强化“资产沉淀”心智

推荐触达：
- 很多用户这时候最大的变化，是开始把好用的流程存下来。你一旦有了自己的模板库，后面效率会完全不一样。

### 4. 第十四天留存

- 引导进入社区分享、发布、克隆
- 让用户获得被看见和被复用的反馈

推荐触达：
- 你现在如果已经有比较满意的流程，可以考虑发布出去。最好的反馈不是别人夸你好看，而是别人直接克隆你的方法。

## 常见转化问题回答

### 用户问：我不会搭节点怎么办？

你不用一开始就学会全部节点。最轻松的方式是从模板或社区现成流程起手，再用 Agent 帮你解释和改造。

### 用户问：我已经有自己的模型 Key，还有必要用吗？

有必要。你可以把它当成工作台和流程层来用，而不是一定买平台模型。自带 Key 模式就是给这类用户准备的。

### 用户问：为什么不直接用 ChatGPT 或 Midjourney？

因为单点工具更像一次性生成器，这里更像能持续复用的生产流程。你不是只拿一个结果，而是在积累方法。

### 用户问：这个适合谁？

适合内容创作者、小工作室、AIGC 接单者、视频和广告方向团队，也适合想把 AI 从试玩变成稳定产能的人。

## 社群日常话题方向

1. 本周最值得克隆的工作流
2. 本周 Agent 优化前后对比
3. 模板改造挑战
4. 一条流程生成三种风格结果
5. 自带 Key 降本经验分享
6. 社区作品背后的方法拆解
7. 工作流复盘：为什么这一条更稳定

## 10 条私域短话术

1. 先别从空白画布开始，直接拿模板跑一遍。
2. 这个产品最值钱的不是生成一次，而是下次还能沿着原流程继续做。
3. 你现在不缺模型，缺的是一条能稳定复用的方法。
4. Agent 可以先帮你看懂流程，再决定要不要改。
5. 平台模式适合先上手，自带 Key 模式适合后面控成本。
6. 先做出第一版，再谈优化，这是最快的路径。
7. 真正的效率提升，来自你开始复用自己的流程。
8. 社区里不只是看结果，更重要的是能直接拿走方法。
9. 如果你已经有满意结果，下一步就是把它沉淀成模板。
10. 一旦开始连续生产，升级的意义会比第一次体验时大很多。

## 转介绍激励表达角度

- 不是邀请朋友来“看看”
- 而是邀请朋友来“直接克隆一条你验证过的流程”

推荐话术：
- 如果你身边也有人在做 AI 内容创作，可以直接把这条工作流发给他。比起发结果图，发方法更有说服力。

## 私域承接顺序建议

1. 先讲“这是什么”
2. 再讲“第一步怎么开始”
3. 再讲“为什么它和别的工具不一样”
4. 然后讲“你用熟以后怎么更省、更稳、更快”
5. 最后引导发布、克隆、模板沉淀，形成留存闭环
