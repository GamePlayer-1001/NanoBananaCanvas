# 公域宣传卖点与内容钩子

## 一、项目一句话定位

Nano Banana Canvas 不是“又一个 AI 生成器”，而是把 **提示词、参考图、模型调用、Agent 辅助、图像生成、视频生成、公开分享、计费结算** 全部放进同一张画布里的 **可视化 AI 工作流平台**。

适合对外反复使用的一句话版本：

1. 把 AI 生成，从“单次出图”升级成“可复用工作流”。
2. 把提示词、模型和交付过程，收回到一张看得见的画布里。
3. 不只是生成内容，而是把整条 AI 生产链保存下来。

## 二、真正的差异点

### 1. 不卖“单次结果”，卖“整条生产流程”

多数 AI 产品交付的是一次结果，下一次还要重新来。

这个项目交付的是：

1. 可视化工作流
2. 可复用节点链路
3. 可继续编辑的创作上下文
4. 可分享、可克隆、可复盘的生产结构

适合传播的话术：

1. 别再让好提示词死在聊天记录里。
2. 别再让 AI 工作流藏在你脑子里。
3. 不是生成一张图，而是沉淀一条以后还能继续赚钱的流程。

### 2. Agent 不是聊天玩具，而是工作流搭建助手

项目里的 Agent 不只是“回答问题”，而是能围绕当前画板做：

1. 生成工作流提案
2. 基于模板改造工作流
3. 诊断为什么跑不通
4. 解释当前流程在做什么
5. 优化成本、结构与执行路径
6. 记录审计与回放

适合传播的话术：

1. 你不用从 0 摆节点，直接说目标，Agent 帮你起草流程。
2. 你不是在和机器人闲聊，而是在让它帮你搭生产链。
3. 从“我想做一个服装商品视频流程”开始，而不是从空白画布开始。

### 3. 平台托管模式 + 自定义 API Key 双模式

这点是非常强的转化钩子。

项目支持：

1. 平台模式：直接用平台额度跑
2. API Key 模式：接入自己的 Key 跑

它解决的是两个完全不同的人群：

1. 新手要的是马上可用，不想配一堆 Key
2. 老手要的是自己控成本、控模型、控供应商

适合传播的话术：

1. 新手直接开跑，高手自己接 Key。
2. 想省事就用平台，想控成本就接自己的 API。
3. 不是强迫你绑定单一生态，而是给你保留模型自由。

### 4. 图像、视频、音频都能进入同一条工作流

项目不是只做文本，也不是只做图片。

当前真实主链已经覆盖：

1. 文本 / LLM
2. 图像生成
3. 视频生成
4. 音频生成
5. 视频分析

适合传播的话术：

1. 从一句话，到一张图，再到一条视频，全部放在同一张画布里。
2. 不再是“AI 图像工具”或“AI 视频工具”，而是多模态生产工作台。
3. 每个输出都能成为下一个节点的输入。

### 5. 公开广场 + 工作流模板 + 克隆复用

项目不是只做个人创作，还带有社区增长属性。

当前已有：

1. Explore 广场
2. 工作流发布
3. 公开作品发布
4. 点赞 / 收藏 / 克隆 / 举报
5. 工作流模板浏览与复用

适合传播的话术：

1. 你不仅能自己做，还能直接拿别人验证过的流程来改。
2. 公开的不只是结果，还有可以直接克隆的工作流。
3. 好流程会沉淀成模板，而不是每次从头搭。

### 6. 真正面向“创作者团队”和“工作室”，不是只面向极客

这个产品的叙事不应该只讲技术，更应该讲协作价值：

1. 画布可读
2. 流程可解释
3. 交接更清晰
4. 模型选择可见
5. 执行结果可追踪

适合传播的话术：

1. 把“我自己知道怎么跑”变成“团队都看得懂怎么跑”。
2. 不是一个人的提示词黑箱，而是团队共享的生产白板。
3. 创意、执行、复盘、交接，可以在同一套工作流里完成。

### 7. 有商业化与账本系统，不是 Demo 产品

项目已经接回：

1. Stripe Checkout / Portal
2. 订阅体系
3. 一次性套餐
4. 积分包
5. credits 冻结 / 确认 / 退款账本

这个点不一定直接当主传播点，但非常适合用于建立信任：

1. 它不是玩具站。
2. 它不是只有 UI 的假平台。
3. 它已经具备持续运营的基础结构。

适合传播的话术：

1. 不是做给演示看的，而是按真实使用和真实结算来设计的。
2. 从创作到计费闭环，已经是一套完整产品，而不是一个壳。

## 三、最适合外宣的卖点分类

### A. 功能层卖点

1. Agent 帮你搭工作流，而不只是陪聊。
2. 一句话起手，直接生成工作流骨架。
3. 平台模式和自定义 API Key 模式都支持。
4. 图像、视频、音频、LLM 在一张画布里协作。
5. 可视化节点链路，比聊天记录更适合复盘。
6. 模板可改造，工作流可克隆，经验可复用。
7. 支持公开发布、收藏、点赞、克隆和传播。
8. 支持视频分析，能把视频拆成分镜和洞察。
9. 自动保存，工作流资产不会丢在零散工具里。
10. 执行状态、任务历史、结果沉淀都是一套链路。

### B. 效率层卖点

1. 少开很多标签页。
2. 少做很多复制粘贴。
3. 少丢很多上下文。
4. 少花很多“我上次到底怎么跑出来的”时间。
5. 把一次灵感变成长期可复用的生产资产。

### C. 价格层卖点

1. 有 Free Trial，用户上手门槛低。
2. 不同档位可覆盖个人、高频创作者、小团队、工作室。
3. 不只是订阅，还支持一次性套餐和积分包。
4. 不想用平台额度，可以走自己的 API Key。
5. 给用户两种心智：省事 vs 控成本。

### D. 身份层卖点

1. 适合个人创作者
2. 适合内容团队
3. 适合设计工作室
4. 适合代理商
5. 适合跨时区协作者
6. 适合做 AI 生产 SOP 的团队

## 四、公域最容易打爆的传播钩子

### 1. 对传统 AI 工具痛点的反击

1. 为什么你做了 100 张 AI 图，最后什么都没沉淀下来？
2. 为什么你的提示词一多，工作流反而越来越乱？
3. 为什么 AI 工具越多，你的效率反而越低？
4. 为什么团队用了 AI，却更难交接？

### 2. 对“结果导向”产品的反差表达

1. 别再只追结果，真正值钱的是流程。
2. 真正拉开差距的，不是一张图，而是一条能重复跑的链路。
3. 会出图的人很多，会沉淀 AI 工作流的人很少。

### 3. 对“工作流资产化”的表达

1. 让每次试出来的好结果，都变成下次还能复用的模板。
2. 把偶然灵感，变成稳定产能。
3. 把你脑子里的经验，变成团队可克隆的系统。

### 4. 对新手友好的表达

1. 不懂节点没关系，先说目标，Agent 帮你搭。
2. 不想折腾 API Key，可以先用平台模式。
3. 从免费试用开始，不需要一上来就学复杂配置。

### 5. 对老手友好的表达

1. 你可以自己接 Key，不被平台成本绑死。
2. 你可以自己选择模型、供应商和路由。
3. 你不只是换个壳，而是给现有 AI 生产方式加一层真正可复用的工作流系统。

## 五、可直接复用的标题方向

1. 这不是 AI 出图工具，这是 AI 工作流操作系统
2. 为什么真正厉害的团队，不再把提示词留在聊天记录里
3. 一个画布，搞定提示词、出图、视频和复用模板
4. 新手直接跑，高手接自己 API Key，这种 AI 平台才合理
5. 你缺的不是更多模型，你缺的是一套能复用的工作流
6. 别再反复重做 AI 流程了，把它沉淀成模板
7. 从一句话到一条视频，这个平台把 AI 生产链接起来了
8. AI 创作最浪费时间的，不是生成，而是上下文丢失
9. 为什么说 Agent + 工作流画布，才是下一代 AI 创作界面
10. 做 AI 内容的人，迟早都要拥有一套自己的流程资产库

## 六、公域内容建议优先级

### 第一优先级：认知教育

1. 为什么“AI 结果”不如“AI 工作流”值钱
2. 为什么创作者最终都会需要工作流资产化
3. 为什么团队用 AI 之后，交接反而更重要

### 第二优先级：功能打点

1. Agent 搭工作流
2. API Key 双模式
3. 图像到视频接力
4. 模板克隆和公开复用
5. Free Trial 和低门槛试用

### 第三优先级：案例型内容

1. 用一张画布做海报流程
2. 用一张画布做短视频流程
3. 用模板改造行业工作流
4. 用自己的 API 降成本

## 七、核心结论

这个项目最值得放大的差异，不是“模型更多”，而是：

1. 把 AI 生产流程从碎片工具里收回来
2. 把一次生成升级成长期可复用的工作流资产
3. 让新手能立即开始，让老手保留成本和模型控制权
4. 让个人创作、团队协作、公开传播和商业化放在同一个系统里

如果公域只能记住一句话，建议用：

**把提示词、模型、图像、视频和 Agent，全都放进一张能复用的 AI 工作流画布里。**
