# Nano Banana Canvas - 公域宣传卖点与内容钩子

> 用途：给短视频、投放素材、落地页、SEO 内容、社区发帖统一对外口径。

## 一句话定位

不是单点 AI 出图工具，而是把多模型、多模态、Agent 助手、工作流复用放进同一张画布的 AI 创作操作系统。

## 核心宣传主轴

### 1. AI 工作流画布

- 不是生成一次结果，而是搭一条可复用的创作流程
- 把文本、图片、视频、音频、LLM 调用串成一条生产链
- 从灵感到成片，不再反复切换多个工具

### 2. Agent 辅助搭建

- 不是只会聊天的 AI，而是懂画布结构的工作流助手
- 可以帮你诊断、解释、优化、改造模板
- Agent 负责提案，画布负责执行，创作者始终掌握最终控制权

### 3. 多模型统一入口

- 一个入口调度多家模型，而不是被单一模型绑定
- 支持平台模型直接跑，也支持用户自带 API Key
- 新手可以无门槛上手，专业用户可以自己控模型、控成本、控供应商

### 4. 社区复用与模板裂变

- 不只看作品，还能看背后的流程
- 可以发布、浏览、收藏、克隆工作流
- 好作品不是一次性消费，而是可复用的生产资产

## 最值得主打的差异点

### 差异点 1：从“生成结果”升级到“管理流程”

- 多数工具只交付一张图或一段视频
- 这个产品交付的是可重复执行、可继续修改、可分享的流程资产

### 差异点 2：平台模式与自带 Key 双模式并存

- 小白可以直接使用平台能力
- 老手可以切到自带 Key，减少锁定感和成本焦虑

### 差异点 3：Agent 真正嵌进生产链，而不是独立聊天窗

- 能理解节点、工作流、模板、执行上下文
- 能做创建、诊断、解释、优化、模板改造，而不是泛泛聊天

### 差异点 4：作品社区和流程社区同时存在

- Explore 解决“看什么”
- Workflows 解决“怎么做”
- 结果和方法两层内容都能沉淀

## 公域内容角度库

### 认知教育角度

- 为什么单次提示词工具不够用了
- 为什么创作者真正缺的是流程，而不是更多模型
- 为什么未来 AIGC 工具会从“生成器”进化成“工作台”

### 效率展示角度

- 一个项目如何串起多个模型
- 一个工作流如何重复生产不同版本内容
- Agent 如何把抽象需求翻译成可执行流程

### 对比角度

- 与单模型工具对比
- 与裸 API 平台对比
- 与纯聊天式 Agent 对比
- 与传统剪辑和设计工作流对比

### 用户故事角度

- 个人创作者如何从灵感到成片
- 小团队如何统一生产流程
- 接单团队如何沉淀可复用模板

## 建议统一口径

### 推荐外宣主口径

- 免费进入工作台
- 可使用平台模式快速体验
- 进阶用户可接入自己的 API Key
- 订阅、一次性套餐、积分包覆盖不同创作节奏

### 不建议混用的口径

- 免费开始
- 免费试用
- Standard 试用
- 签到试用积分

原因：这些都是真实存在的产品口径，但如果在同一广告或同一篇内容里混用，会让用户误解“是否必须绑卡”“到底免费到哪一步”。

## 推荐传播顺序

1. 先打“AI 工作流画布”认知
2. 再打“Agent 帮搭流程”差异
3. 再打“平台模式 + 自带 Key”降低门槛
4. 最后打“模板、社区、克隆”形成复用和裂变心智
